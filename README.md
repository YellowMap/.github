# YellowMap

YellowMap AG develops **SmartMaps**, a map platform hosted in Germany. Maps, geocoding, autocomplete, routing and further geo services are available through one API key.

We have been working with geodata since 1999. YellowMap is based in Karlsruhe and is part of the CAS Group.

## SmartMaps

| Service | What it does |
|---|---|
| Maps | Interactive vector maps with SmartMaps GL JS, plus static map images |
| Geocoding | Address to coordinates and back, also as batch |
| Autocomplete | Address suggestions while typing, in 25 languages |
| Routing | Routes, matrix routing, isochrones and trip optimisation |
| Further services | Weather, administrative areas, elevation, time zones |

Coverage: 140+ countries. Documentation: [docs.smartmaps.cloud](https://docs.smartmaps.cloud/)

## Built on open source

- Map data comes from [OpenStreetMap](https://www.openstreetmap.org/).
- SmartMaps GL JS is built on [MapLibre GL JS](https://maplibre.org/). The docs include a migration guide from Mapbox GL.
- We maintain our own vector tile schema and map styles: essential, light, dark, grey, accessible and satellite. By default, the base maps show no third-party points of interest, so your own locations stay in focus.

## Privacy

- Hosted exclusively in ISO 27001-certified data centres in Germany
- No cookies and no tracking, not even first-party
- Data processing agreement under Art. 28 GDPR for every customer
